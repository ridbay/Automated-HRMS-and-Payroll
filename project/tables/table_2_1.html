Table 2.1: Cloud service delivery models compared

Delivery model What the provider manages What the consumer manages Billing basis Representative example
Infrastructure as a Service (IaaS) Physical hardware, data centre, networking, and the virtualisation layer Operating system, patching, runtime, middleware, application, data, and capacity sizing and scaling Allocated capacity (instance size) per unit of time, charged whether or not it is used Amazon EC2; DigitalOcean Droplets
Platform as a Service (PaaS) Everything in IaaS, plus the operating system and runtime environment Application code and data, and the number and size of running instances Provisioned instances or plan tier per unit of time Heroku; Google App Engine
Software as a Service (SaaS) The complete application, including its infrastructure, runtime, data storage, and updates Configuration of the application and the data entered into it Subscription, typically per user or per employee per month Commercial cloud HRMS suites of the kind reviewed in Section 2.10.2
Function as a Service (FaaS) / Serverless Everything below the code: runtime, scaling, and capacity, with execution environments started on demand and released when idle Function code and the data it reads and writes only Per invocation and execution time consumed, rather than allocated capacity; no usage charge while idle, though some plans carry a fixed minimum fee Cloudflare Workers (the platform adopted in this project); AWS Lambda
