HTTP request
From the SPA, with the bearer token in the Authorization header
Routes
Map path and method to a middleware chain and a controller; no logic
/auth /public /employee /admin /ai /support
Middlewares
authMiddleware: verify JWT; set employee, company (tenant), and role
requireRole: fixed-role allow-list
requirePermission: custom-role narrowing
Rejection here short-circuits the request
Controllers
Parse request · call one service · shape response
Services
All business logic and computation: payroll engine, leave rules, transition state, assistant tools
Models
(Drizzle)
Typed table schemas; the only layer that knows table shape
401 / 403 response
No controller, service, or query runs
Settings and Control Centre routes call their services directly (documented deviation, Section 3.2.2)
